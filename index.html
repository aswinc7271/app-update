Questions

How do app updates work?

V17 checks for newer releases when you open the app. Update now opens the APK download in your browser; Android asks you to confirm installation. V14 needs one manual update; V15 can discover V17 after the feed is published. Installing V17 when V17 is the latest correctly shows no newer update.

Is the APK safe?

Compare the SHA-256 with the downloaded file to check integrity. A matching checksum does not prove app safety. Build and signature checks passed; device testing is still required.

Android blocks the install

Open Settings, search “Install unknown apps”, and allow it for the browser you downloaded with. Then open the file again.

Will I lose my data when updating?

Updates with the same package name and signing key normally preserve settings. Install over the existing app; uninstalling can remove data.
